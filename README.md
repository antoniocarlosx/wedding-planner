# 💍 Noivei e Agora?

> Um planejador de casamento para ajudar os noivos a transformar ideias em um evento organizado — e descobrir quanto tudo isso vai custar.

**Noivei e Agora?** é uma aplicação web criada para simular o planejamento de um casamento de forma simples, visual e interativa.

A ideia é permitir que os noivos escolham diferentes elementos do evento — como espaço, decoração, gastronomia e serviços — enquanto acompanham a composição do orçamento em tempo real.

---

## 🎯 Objetivo

Planejar um casamento envolve muitas decisões:

* Quantas pessoas serão convidadas?
* Qual espaço combina com o evento?
* Quanto será gasto com alimentação?
* Que decoração será necessária?
* Quais serviços precisam ser contratados?
* Quanto tudo isso vai custar?

O **Noivei e Agora?** transforma essas decisões em uma experiência de planejamento mais simples.

A aplicação funciona como um **Wedding Planner digital**, permitindo montar o evento a partir de diferentes opções e visualizar o impacto de cada escolha no orçamento.

---

## ✨ Funcionalidades

### 👰 Planejamento do evento

O usuário pode montar seu casamento escolhendo diferentes categorias:

* 🌸 Local & Cerimônia
* 🌿 Decoração & Ambientação
* 🎻 Som & Cerimônia
* 🥂 Gastronomia & Recepção
* 💐 Experiência dos Noivos
* 📸 Memórias

### 👥 Quantidade de convidados

A quantidade de convidados influencia diretamente algumas escolhas e custos do evento.

Por exemplo:

> Brunch Elegante — R$ 25 por pessoa
> 40 convidados × R$ 25 = **R$ 1.000**

### 💰 Orçamento

O sistema calcula automaticamente o custo das escolhas realizadas pelo usuário.

O objetivo é permitir que o casal acompanhe:

**Itens escolhidos → Subtotal → Custo por pessoa → Total do casamento**

### 🛍️ Seleção de serviços

Cada item possui informações como:

* Nome
* Categoria
* Descrição
* Preço
* Capacidade, quando aplicável
* Tipo de cobrança

## 🎨 Conceito visual

A identidade visual busca transmitir:

**romance + elegância + simplicidade**

A interface deve ser agradável sem deixar de ser funcional. O objetivo não é criar apenas uma página bonita, mas uma experiência em que o usuário consiga entender facilmente:

1. O que está escolhendo;
2. Quanto custa;
3. O que já foi selecionado;
4. Quanto já gastou;
5. Quanto falta para completar o planejamento.
